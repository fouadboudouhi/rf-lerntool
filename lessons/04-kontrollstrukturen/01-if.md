---
title: Bedingungen mit IF
---
Mit `IF` führst du Schritte nur unter einer Bedingung aus. Die Bedingung ist ein **Python-Ausdruck**, Variablen darin schreibst du am besten als `$name` (ohne geschweifte Klammern), dann werden sie als echte Werte statt als Text eingesetzt.

```robot
*** Test Cases ***
Beispiel
    ${betrag}=    Set Variable    ${250}
    IF    $betrag > 100
        Log    Großer Betrag
    ELSE IF    $betrag > 10
        Log    Mittlerer Betrag
    ELSE
        Log    Kleinbetrag
    END
```

- Der Block endet immer mit `END`.
- `ELSE IF` und `ELSE` sind optional.
- Textvergleiche brauchen Anführungszeichen: `IF    $status == "OK"`.
- Für eine einzelne Zeile gibt es die Kurzform: `IF    $x > 5    Log    Groß`.

## Warum `$name` statt `${name}`?

`${name}` wird **vor** der Auswertung als Text eingesetzt. Bei `${status} == OK` steht dann `OK == OK` da, was Python als Vergleich zweier undefinierter Namen liest und einen Fehler wirft. Mit `$status == "OK"` bekommt Python den echten Wert. Merke: In Bedingungen `$name`, im restlichen Code `${name}`.

## Wann IF und wann nicht

Ein Test mit vielen Verzweigungen ist schwer zu verstehen und prüft je nach Pfad etwas anderes. Besser: **ein Test pro Fall**, und IF vor allem in Keywords für kleine technische Entscheidungen.

## Aufgabe

Schreibe das Keyword `Bewerte Betrag` mit dem Argument `${betrag}`. Es soll loggen:

- `Genehmigung nötig` bei Beträgen über 10000
- `Prüfung nötig` bei Beträgen über 1000
- `Automatisch freigegeben` sonst

Der Test ruft es dreimal auf und ist bereits fertig.

```robot start
*** Test Cases ***
Beträge bewerten
    Bewerte Betrag    ${500}
    Bewerte Betrag    ${5000}
    Bewerte Betrag    ${50000}

*** Keywords ***
Bewerte Betrag
    [Arguments]    ${betrag}
    # IF / ELSE IF / ELSE / END

```
